About & editorial policy

How the index works.

GAP Index is an independent editorial project. It publishes absolute provider scores for ten AI ecosystems and a separate monthly Anthropic vs OpenAI GAP history. It is not affiliated with any provider, and it is not a poll, market-share audit, or investment recommendation.

How scores are built

Every provider receives a 0–100 score on the same four weighted factors. The weighted total is computed, not hand-entered. The monthly GAP history uses a separate relative scale where 50 is parity.

FactorWeightWhat it covers
Subscription value and usage limits30%Plan value, included usage, limits, and access friction.
Model capability and reliability30%Capability, consistency, tool use, and practical reliability.
Coding and agent workflows25%Coding tools, agent execution, terminal/browser work, and developer pull.
Ecosystem, distribution, and integrations15%Distribution, integrations, enterprise availability, and developer ecosystem.

Provider score: 0–49 developing, 50 mid-field, 51–100 leading. GAP vs. OpenAI: 0 = OpenAI edge, 50 = parity, 100 = Anthropic edge. These are different scales and are labeled separately in the interface and API.

Source policy

Each provider has at least one primary source (the provider's own pricing or news page) and at least one independent source (a third-party benchmark, traffic estimate, or developer survey). Citation coverage is __COVERAGE_CITED__/__COVERAGE_TOTAL__ for monthly entries and __INDEPENDENT_SOURCES__/__PROVIDER_COUNT__ for independent provider corroboration.

A link is not proof that every claim is correct. Sources are context for an editorial judgment. When a source is stale, paywalled, or changes, the score should be reviewed rather than treated as permanent.

Corrections

If a score, source, or label is wrong, open an issue on GitHub Issues with the month, provider, and the evidence. Corrections that change a published score are recorded in the changelog below. The site does not silently rewrite a score without a note.
