05 QUICK ANSWERS

AI providers, explained.

What does the GAP Index measure?

It publishes absolute editorial provider scores for ten AI ecosystems on a 0–100 scale, using subscription value, model capability, coding/agent workflows, and ecosystem reach. It also keeps a separate monthly Anthropic vs OpenAI GAP history, where 50 is parity.

Does a higher provider score mean that company is always better?

No. A provider score is an editorial synthesis, not a universal recommendation. Coding-heavy work, research, image generation, enterprise controls, privacy needs, regional availability, and personal usage limits can lead to different choices.

Where can I compare current prices and limits?

Prices, model access, and usage limits change. Always verify them on the official provider pages linked from each provider detail page before subscribing. This index does not promise real-time plan prices.

Can an AI agent query the index without scraping this page?

Yes. Use /api/index.json, /api/providers.json, /api/history.json, and /api/news.json. The site also publishes llms.txt, RSS, and a Markdown overview for simpler tool ingestion.
